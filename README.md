## 🚀 Overview

This repository contains the source code for my personal portfolio website. Designed with a deep, dark-themed UI featuring colorful gradient accents and glassmorphism effects, it serves as a digital resume and a central hub for my development projects, technical skills, and contact information.

## ✨ Features

* **Modern UI/UX:** A stunning dark theme with floating gradient auras, glowing hover effects, and smooth transitions.
* **Fully Responsive:** Fluid design that adapts seamlessly to desktops, tablets, and mobile devices.
* **Dynamic Typing Effect:** Engaging hero section featuring `Typed.js` for dynamic text animation.
* **Glassmorphism Navbar:** A sticky, frosted-glass navigation bar for easy scrolling across sections.
* **Functional Contact Form:** Integrated with FormSubmit (and an alternative `mailto:` fallback) for direct communication.
* **Performance Optimized:** Lightweight pure CSS and Vanilla JavaScript with no heavy frameworks.

## 🛠️ Technologies & Tools Used

* **Frontend:** HTML5, CSS3 (CSS Variables, Flexbox, CSS Grid)
* **Scripting:** Vanilla JavaScript
* **Libraries:** [Typed.js](https://github.com/mattboldt/typed.js/) (for the typing animation effect)
* **Form Handling:** FormSubmit API
* **Design Elements:** Custom gradients, CSS backdrop filters, and CSS keyframe animations.
